# ArchWise 微服务运行说明

当前默认入口已经调整为 API 网关，项目按四个独立 FastAPI 进程运行：

| 服务 | 默认端口 | ASGI 入口 | 职责 |
| --- | ---: | --- | --- |
| API 网关服务 | 8010 | `app.main:app` | 托管前端页面，转发推荐、知识、LLM 状态等请求 |
| 推理编排服务 | 8011 | `app.reasoning_main:app` | 执行需求解析、架构匹配、规则校验、报告生成和拓扑生成 |
| 知识服务 | 8012 | `app.knowledge_main:app` | 管理架构风格、案例库、Neo4j 拓扑知识和知识维护接口 |
| LLM 网关服务 | 8013 | `app.llm_gateway_main:app` | 代理聊天模型和 Embedding 模型，提供 OpenAI-compatible `/v1` 接口 |

启动命令：

```powershell
.\scripts\start_microservices.ps1
```

停止命令：

```powershell
.\scripts\stop_microservices.ps1
```

如果默认端口被占用，可以指定端口：

```powershell
.\scripts\start_microservices.ps1 -GatewayPort 8110 -ReasoningPort 8111 -KnowledgePort 8112 -LlmGatewayPort 8113
```

访问入口：

```text
http://127.0.0.1:8010
```

验证服务状态：

```powershell
Invoke-RestMethod http://127.0.0.1:8010/health/services
```

关键环境变量由启动脚本按服务注入：`REASONING_SERVICE_URL`、`KNOWLEDGE_SERVICE_URL`、`LLM_GATEWAY_SERVICE_URL`、`LLM_BASE_URL`、`EMBEDDING_BASE_URL`。推理服务和知识服务通过 `http://127.0.0.1:8013/v1` 调用 LLM 网关，推理服务通过 `http://127.0.0.1:8012` 调用知识服务。

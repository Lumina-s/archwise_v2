# ArchWise 系统测试报告

> 对照当前真实实现编写。系统按四个微服务运行；单元/集成测试在进程内（单体）模式下执行。

## 1. 测试范围

覆盖：需求解析与结构化校验、候选架构推荐、LangChain 结构化输出链、embedding 封装、Neo4j 向量、Chroma 案例记忆、推荐缓存与 LLM 缓存、知识规范化/语义去重、微服务边界契约、拓扑生成与覆盖率自检、Web API 可用性与典型场景。

## 2. 自动化测试

测试位于 `tests/`，共 **9 个测试文件、约 48 个用例**：

| 测试文件 | 目标 |
| --- | --- |
| `test_recommendation.py` | 端到端推荐：≥3 候选、对比矩阵、Agent 协作 trace、错误路径 |
| `test_topology_generator.py` | 定制拓扑：领域能力覆盖、组合架构建图、单例去重、覆盖率自检 |
| `test_knowledge_normalizer.py` | 语义近义节点合并、不确定项临时处理、近重复检测 |
| `test_service_boundaries.py` | 微服务边界与接口契约 |
| `test_neo4j_vectors.py` | Neo4j 原生向量索引与拓扑向量检索 |
| `test_recommendation_cache.py` | 推荐结果缓存命中/失效 |
| `test_llm_cache.py` | LLM 结果缓存 |
| `test_llm_structured_chain.py` | LangChain `with_structured_output` 结构化解析 |
| `test_langchain_embeddings.py` | embedding 封装与批处理 |

运行命令：

```powershell
pytest -q
```

## 3. 测试结果（当前）

**46 通过 / 2 失败**。

2 个失败用例均在 `test_recommendation.py` 的端到端推荐路径：

| 失败用例 | 原因（测试隔离，非产品缺陷） |
| --- | --- |
| `test_recommend_im_returns_at_least_three_candidates` | 端到端推荐用例直接命中**真实持久化的 Chroma 案例集合**（生产为 1024 维通义向量），与测试提供的假向量维度不一致而报错 |
| `test_recommend_returns_prompt_when_deepseek_parse_unavailable` | 错误路径用例的 mock 装配与重构后的流程不完全匹配 |

说明：以上是**测试卫生 / 隔离**问题——端到端用例未与真实持久化的 Chroma / 服务隔离开，而非系统功能缺陷。产品功能已通过其余 46 个用例、手工验收与实际运行验证（案例库已自然沉淀多条运行时候选案例、推荐/对比/拓扑/知识中心均正常）。
**改进方向**：给案例记忆相关测试使用临时 Chroma 集合并对齐向量维度，使端到端推荐用例可离线确定性通过。

## 4. 典型场景测试数据集（≥20）

`data/test_cases.json` 含 **20 个典型需求场景**（即时通讯、电商、OA、大数据、在线教育、物联网、金融支付、游戏后端、医院挂号、物流追踪、短视频、智慧城市、博客、供应链、在线考试、社交媒体、工业控制、图书管理、旅游预订、AI 绘画）。这 20 条同时作为案例记忆的**冷启动可信种子**。

## 5. 手工验收步骤（微服务）

1. 启动四服务：`./scripts/start_microservices.ps1`
2. 打开 `http://127.0.0.1:8010`
3. 输入需求（或点示例/场景标签）→ "开始分析"，观察三个 Agent 协作动画
4. 结果页四 Tab 验证：推荐总览（主推荐 + 备选 + 组合）、对比分析（雷达 + 柱状 + 矩阵）、架构拓扑（Mermaid 可缩放平移）、决策溯源（需求特征 → 规则 + 案例记忆 → 匹配信号）
5. 知识中心：概览计数、风格/拓扑图谱（vis-network）、案例库（新增/删除/提升可信）
6. 健康检查：`Invoke-RestMethod http://127.0.0.1:8010/health/services`
7. Web API：各服务 `/docs`

## 6. 决策结果可解释性验证

每次推荐返回结构化 `decision_trace`，前端"决策溯源"Tab 以人话三步展示：① 需求特征提取（质量属性 % + 模糊点）；② 规则引擎命中 + 案例记忆检索；③ 各候选匹配信号（原始分等技术细节折叠）。可逐项核对推荐依据，满足"决策结果可解释性验证"。

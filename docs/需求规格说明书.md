# ArchWise 需求规格说明书

> 面向"软件体系结构风格智能助手"课程大作业。本文档对照当前真实实现编写。

## 1. 项目目标

接收用户自然语言软件需求，自动完成语义特征抽取、候选架构推荐（≥3 种）、多维度对比、最终决策报告、架构组合推荐与定制拓扑图生成，并具备案例学习（知识进化）能力。系统以四个独立微服务承载，推理由多智能体（LangGraph）协作完成，决策为"大模型 + 规则引擎 + 本地匹配器 + 历史案例"的混合推理。

## 2. 用户与使用场景

- **架构学习者 / 学生**：输入需求，理解不同架构风格的适用场景与取舍。
- **课程验收人员**：通过 Web 页面与 Web API 验证系统具备多智能体协作、LLM 集成、知识图谱、混合推理、可视化与知识进化能力。
- **知识维护者**：在知识中心补充/删除案例、提升候选为可信、查看图谱与进化状态。

## 3. 功能性需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-01 | 需求理解 | 抽取领域、关键词、业务能力、并发/实时/可靠/扩展/数据密集/AI 推理质量属性、数据流类型、部署约束与模糊点 |
| FR-02 | 架构推荐 | 至少输出 3 种候选体系结构风格（含主流：分层/微服务/事件驱动等） |
| FR-03 | 决策支持 | 评分、推荐理由、风险、优缺点、最终推荐、置信度，多维对比矩阵与雷达 |
| FR-04 | 知识库 | 内置 ≥10 种（实为 12 种）架构风格属性、适用场景、拓扑与规则，构成知识图谱 |
| FR-05 | 混合推理 | 大模型生成候选，规则引擎做硬约束事后校验/重排，本地匹配器交叉打分，历史案例作可选参考注入 |
| FR-06 | 架构组合推荐 | 单一风格不足时给出主架构 + 支撑架构及职责，并提示过度设计风险 |
| FR-07 | 定制拓扑生成 | 按本次需求动态生成可缩放/平移的 Mermaid 架构拓扑图 |
| FR-08 | 知识进化 | 运行时案例自动捕获（去重合并）+ 人工策展（增删/提升可信）+ 检索注入闭环；拓扑图谱可进化 |
| FR-09 | 可视化 | 三阶段体验、四 Tab 结果、决策溯源、知识中心（图谱 + 案例库） |
| FR-10 | Web API | 推荐、知识库/图谱查询、案例增删与提升、健康检查等接口 |

## 4. AI 系统特有需求（对 AI 不确定性的处理方案）

AI 推荐天然存在不确定性与幻觉风险，系统从五个角度处理：

- **不确定性显式化**：需求解析输出 `ambiguity_notes`（模糊点）与各候选的**置信度**等级，把"模型不确定"如实呈现，而非假装唯一答案。
- **知识只作加法、不裁决**：历史案例检索到才注入、且仅作"可选参考"；未命中就不注入，让大模型照常发挥——单条知识/案例无法劫持推荐结果。
- **规则引擎兜底校验**：大模型候选必须经规则引擎硬约束校验，明显违规则降权重排，降低幻觉对最终结果的影响。
- **可解释 / 可追溯**：每次推荐产出结构化 `decision_trace`（需求特征、规则证据、案例记忆证据、本地匹配证据、评分证据、LLM 复核、组合证据、缓存证据、最终理由），逐项可追溯。
- **人在回路的知识质量门槛**：运行时学到的案例先入"候选"，需人工确认才"可信"；人工新增也默认候选并在提交前做重复/矛盾提示，防止低质知识污染检索集合。

## 5. 非功能需求

| 维度 | 要求与实现 |
| --- | --- |
| 性能/响应 | 评估报告 SSE 流式推送、拓扑与报告并行、案例沉淀转后台执行不阻塞响应；`recommendation_cache` + `llm_cache` 对相似/重复需求提速 |
| 可扩展性 | 四个独立服务可分别伸缩；知识用 Neo4j（图）+ Chroma（向量）持久化，可独立扩容；新增风格/案例即时进入后续推荐 |
| 可维护性 | `api / services / agents / knowledge / models` 分层；服务间走明确 HTTP 契约；**同一套代码靠环境变量切换单体/微服务** |
| 安全 | 模型密钥集中在 LLM 网关服务，推理/知识服务只认 OpenAI 兼容接口、不直接持密钥 |
| 可靠性 | LLM 输出经 Pydantic 结构化校验；规则引擎二次校验；拓扑节点单例去重与边合法性校验；LLM 调用带超时；服务级异常返回清晰错误 |
| 可观测性 | 决策溯源 + Agent 协作追踪 + `/health/services` 聚合健康检查；运行树/LangSmith 列为未来增强 |
| 可演示性 | Web 页面 + `/docs`；四服务一键启动脚本（`scripts/start_microservices.ps1`） |
